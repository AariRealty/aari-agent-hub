Those techniques are carried over here. None of its colours or type are. Everything below is Aari's own palette, and the display face is Cormorant Garamond — the serif the Hub already names in --serif.

The reference is built around a gold, #EDB40B. There is no gold here. Where it used gold, this uses taupe — #c9bfa8 — which is already ours.

Every figure on these screens is a real one. They come from realty_transactions, realty_listings, realty_members, realty_agent_goals and the two Google calendars the Hub already reads. Where the Hub does not hold something — showings, signed agreements — the screen says the number is zero rather than showing a flattering one. Nothing on this page is illustrative.
