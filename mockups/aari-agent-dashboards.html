Option 1Where’s my money

Opens on the one thing an agent checks the Hub for: the commission they are waiting on. The hero is the file itself, with a four-stop rail showing where it has got to and where it has stopped. Below it, what she has actually earned this year, file by file, then her inventory, then the short list of things standing between her and getting paid.

Which one

Option 1. An agent opens the Hub to answer one question, and it is not “what is my week.” Milennys has $17,877 sitting in review on a property that closed sixteen days ago, submitted forty-six days ago, and today she has no way of knowing that. Option 1 makes that the first thing on the screen and shows exactly which stop it is parked at. Nothing else on any of these three pages is worth as much to her.

Option 3 is the one to take if you want them opening it daily. One column, phone-shaped, and the file in review sits in the same list as the coaching call — so checking it is a habit rather than an errand. It is the weakest at explaining why the money is stuck.

Option 2 is the one to take when they have more than a handful of files. One table with lanes scales to twenty properties; the other two do not. Right now Milennys has eight rows in total, so it is solving a problem she does not have yet. Worth revisiting when someone does.

What none of these can do yet, and it is the same gap in all three. Every figure above is gross commission, because net_commission is null and commission_computed_at is null on all fifty-six transactions in the Hub — the split maths has never run. An agent looking at $17,877 cannot tell what actually reaches them. That is a bigger fix than a card, and it sits under whichever of these you pick.
