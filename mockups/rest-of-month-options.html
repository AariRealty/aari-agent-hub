Three ways to lay out the month list

The problem is that only two of the six entries can be attended, so the rows with an RSVP look full and the rest look empty with a date stranded on the right. Each of these solves it differently. Same six entries, all live — the attend and share controls work.

Option ADate rail

A fixed date column down the left, so every row starts on the same line and the right edge stops being the thing holding the list together. Attendance sits under the title, so a row with one is simply taller.

Rest of the month
Option BFixed right column

Keeps the date on the right but gives it a fixed width so every date aligns, with the attend controls in a middle column that collapses when empty. Every row is the same height whether it can be attended or not.

Rest of the month
Option CGrouped, one line

Grouped by week, one line per entry, and attendance reduced to a single round ＋ that never changes the row height. The densest of the three — six entries in about half the space.

Rest of the month

Which one

I would pick B. It is the smallest change from what is there now, it fixes the actual complaint — the dates finally line up in a column instead of floating at the end of whatever the row happens to contain — and rows keep a constant height, so the list reads as a list. A is the better choice if you want the dates to be the first thing you scan, and it matches the classes list you already liked. C fits the most in, but it truncates long titles and hides the attendee faces behind a count.
