Same order, same reds, three quieter ways to draw it

The order stays: database → conversations → appointments → closings. The reds stay, on the two that are still at zero. What changes is how the row is drawn, and all three now fit without swiping sideways, which the first one did not.

The bell was a bug, not a taste problem. I wrote &#9788;, which is a sun, not a bell — a spiked blob with a red badge on it. It is now an envelope drawn as the gear's twin: same circle, same hairline border, same 34px, same colour, with a quiet dark count instead of a red one.
