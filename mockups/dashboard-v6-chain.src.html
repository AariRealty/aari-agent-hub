Three that are not the same as each other

You were right that the first and third were cousins, both were four numbers with small caps under them, one with hairlines and one with dots. These three are a line of type, a set of bars and a single thread. Nothing boxed, nothing bordered, and each one shows the flow rather than just listing four counts.

The gear is untouched, same glyph, same circle. The mail is now its twin: the same character-drawn approach at the same size and weight, so the pair reads as one set. I did not use the colour emoji: 📧 renders in blue and white on a phone, and this bar has no colour in it anywhere. If you would rather have the literal emoji, say so and it is a one-line change.
