Your dashboard is not changing. Everything above this band — your photo, your income, the ring, Today, the calendar, Path to first close, Announcements — stays exactly as it is. This is only the new band, drawn three ways. Every pattern below already exists somewhere on the page, so whichever you pick, nothing new is being introduced to the design.

Which one

Version B. The file is not a money problem, it is a stuck problem — the amount is not what you need to know, the fact that it never left Draft is. A stop line says that in one glance and a big number does not. And the numbered route for what you owe puts it in the same visual language as Path to first close, which sits directly above it — two cards about finishing things, drawn the same way, instead of two strangers.

The cost of B, honestly: it is the least urgent-looking of the three. Version A shouts. If what you want is agents opening the Hub and immediately feeling the pull of unfinished work, A does that better, and the red $319,999 is doing that job.

Version C is the one that ages best and reads worst today. A table for one listing looks thin, and a ledger for two items looks like overkill. Both come into their own at six listings and five outstanding items — which is where Milennys and Roosevelt already are, even if you are not.

Mix them if you want. They are three separate cards and nothing stops you taking B’s stop line, A’s listing row and C’s ledger.
